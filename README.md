# Слова в дорогу

[Открыть карточки](https://ivanoskov.github.io/thai-english-cards/)

160 слов и выражений, 480 коротких примеров. Статический сайт без сборки, зависимостей, регистрации и аналитики.

- Все слова вместе, в случайном порядке. Кнопка внизу открывает три режима. В режиме «Вперемешку» направление случайно выбирается для каждого показа карточки. Режим сохраняется на устройстве.
- Крупный текст и закреплённые внизу кнопки с отступом под системную область телефона. Длинные карточки прокручиваются над панелью действий.
- Нажать на слово — открыть перевод и три примера. Повторное нажатие скрывает ответ.
- Примерно в половине показов рядом со словом есть случайный пример с пропуском вместо английского слова. В остальных показах контекста нет. При раскрытии полное предложение появляется первым среди трёх примеров и становится доступна его озвучка.
- Слово и каждый пример озвучиваются отдельной кнопкой через голос устройства. Наличие английского голоса и работа офлайн зависят от браузера/ОС.
- «Знаю» убирает слово из текущего круга. «Повторить» возвращает после других карточек.
- «Убрать слово» исключает его на данном устройстве и в данном браузере во всех режимах и будущих кругах. Можно сразу отменить удаление. В конце круга доступно возвращение всех убранных слов.
- Прогресс и исключения сохраняются в localStorage; очистка данных браузера их удаляет. Предыдущий прогресс переносится по стабильным id.
- После первого успешного открытия и кэширования карточки доступны офлайн.

`npm start` — HTTP-сервер на порту 8765, Python 3.

`npm test` — данные, перемешивание, повтор, исключения, миграция и сохранение, Node.js 18+.

GitHub Pages: `main`, каталог `/`. При обновлении статических файлов менять версию кэша в `sw.js`.
