# Слова в дорогу

60 русско-английских карточек для путешествий. Статический сайт без сборки, зависимостей и регистрации.

- Карточки в случайном порядке, русский → английский или наоборот.
- Перевод и пример открываются по нажатию; «Знаю» убирает слово из текущего круга, «Повторить» возвращает его после других слов.
- Выбор темы, отмена последней оценки, новый случайный круг после завершения.
- Прогресс сохраняется в localStorage на данном устройстве и в данном браузере. Очистка данных браузера его удалит.
- После первого успешного открытия и кэширования сайт доступен офлайн. Озвучка зависит от голосов браузера/устройства и может требовать интернет.
- Никакой аналитики, серверной базы и отправки результатов.

## Разработка

`npm start` — локальный HTTP-сервер на порту 8765, Python 3.

`npm test` — проверка карточек, перемешивания, повторения и восстановления прогресса, Node.js 18+.

GitHub Pages: ветка `main`, каталог `/`. После изменений в статических файлах обновлять номер кэша в `sw.js`.
